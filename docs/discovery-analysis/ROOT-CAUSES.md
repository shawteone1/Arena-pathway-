## Extraction findings (diagnostic, not original source-discovery explanations)

- HTML block concatenation could fuse a heading with the next paragraph and hide a youth word boundary. Whitespace is now inserted at block boundaries.
- Structured scripts and page-configuration fragments could pollute visible-text qualification. Scripts are removed. A valid JSON wrapper is now explicitly unsupported even when the server labels it text/html; it needs a separate reviewed adapter. VC Denver exhibited this response.
- A directory page title could produce the publisher name instead of the organization. Configurable linked-profile heading selection fixes that where a real organization heading exists. It does not invent an alias or force a club name from the benchmark.
- Foothills Pack's official SEO title is a program description, not its canonical identity. Littleton used escaped newlines. Those are diagnostic identity-normalization issues, not why the original six lacrosse identities were missing. Escaped line breaks are normalized; Foothills still requires source-backed identity review.
- Colorado in a squad name, competition venue or operator biography is not proof of the club's service geography. The matcher now requires a more explicit locality/state phrase and still emits candidates only. It is not a comprehensive semantic verifier: even a locality phrase must be reviewed in context.
