# Benchmark methodology and predeclared acceptance

Protocol commit: `f0429c3f009720cd536c7933074d0e3093f2753d`.
Frozen benchmark/source-census commit: `e7d746e796c98b43e8786ade6c1638a532a5b1c6`.
Initial live trial seal commit: `f2f59be` (full ID is in Git history).

The protocol and benchmark were committed before the trial. SHA-256 locks cover both sport benchmark files and independently read source scopes. The evaluator verifies those hashes and the sealed initial acquisition snapshot. It reads held-out identities only after acquisition; intake jobs do not read benchmark files. Post-trial assisted reviews and parser improvements are not included in initial recall.

Thresholds: 100% prescribed accessible source-scope recall; at least 90% held-out organization recall, 95% precision, 95% classification accuracy, zero unexplained duplicate identities, 100% traceability, 90% source-backed record freshness within 30 days and 90% user-visible recall. Unknown metrics fail acceptance rather than receive a passing value.

Separate development/held-out sets use prior reviewed research and independent official club/program pages or indexed publisher evidence. Six held-out positives per sport are purposive examples, not representative random samples. The same analyst assembled the benchmark and source leads; this is not an externally blinded evaluation. Some evidence was indexed when publisher access was blocked. The benchmark includes positive identities only and cannot establish precision or global classification accuracy. All outputs need independent full-pool adjudication before those metrics can be measured.

Identity recall is not youth-qualified recall. State, participation and youth eligibility must each have evidence. Publication timestamps and retrieval timestamps are not current-membership dates. A club found in a multi-state source is not automatically a Colorado youth club. Source-level 102-entry alternate coverage says nothing about unknown statewide coverage.

The original trial is deliberately preserved even though it fails. A credible next evaluation needs a fresh independently assembled held-out sample after acquisition changes, permitted official source access, full output adjudication and a clear publication review scope. Reusing these now-known identities as new blind answers would invalidate the claim.
