# Arena Pathway development guidance

Before making product, architecture, data-model, integration, or UX changes, read [the Product North Star & Architecture Charter](docs/PRODUCT-NORTH-STAR.md) in full and follow its approved principles.

Do not change the charter's approved principles without explicit user authorization. If the charter is missing or unreadable, obtain the approved document before proceeding with changes in those areas. If a proposed change conflicts with the charter, report the conflict and propose a simpler alternative before implementation; obtain explicit authorization before changing an approved principle.

Preserve the existing application and functionality. Work on a separate development branch. Do not merge, deploy, update GoDaddy/Airo previews, or publish without explicit user approval.
